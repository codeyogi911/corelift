# Issue tracker

Specs live in GitHub Issues on `codeyogi911/corelift`. Read and write them with the GitHub MCP tools or `gh`.

- A PR links its spec with `Closes #<n>` in the body; review step 6 fetches the spec from there.
- Work without an issue writes its acceptance criteria into the PR body under **Spec**, and that section is the spec.
- Issues and PRs carry synthetic examples only. Customer exports, credentials and SAP system details stay out of them.
